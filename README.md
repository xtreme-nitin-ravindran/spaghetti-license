# Spaghetti License

Canonical home of the **Spaghetti License** and its required branding image.

## Stable paths

| Resource            | URL                                                            |
| ------------------- | -------------------------------------------------------------- |
| License text        | <https://spaghetti.nitin.run/license>                          |
| Required image      | <https://spaghetti.nitin.run/brand-spaghetti.jpg>              |
| Git repository      | `git@github.com:xtreme-nitin-ravindran/spaghetti-license.git`  |

## Identifier

`SPDX-License-Identifier: LicenseRef-Spaghetti`

## License requirement

The license is public-domain-like, with one binding condition:

> Any user-facing application that uses this software must visibly display
> the `brand-spaghetti.jpg` image included with this software.

## Files

- `LICENSE` — the license text
- `brand-spaghetti.jpg` — the image that must be visibly displayed
- `.spdx/LicenseRef-Spaghetti.xml` — machine-readable SPDX license metadata
